# Tic Tac Toe

a simple TicTacToe game written in Java

## About
This is a game based for two players. Players take turns placing X and O on a 3x3 board. The first player to get three symbols in a row, column, or a diagonal wins.

## How to play
1. Player X goes first.
2. Enter a number from 1 to 9 to choose a square.
3. Players take turns placing their symbols.
4. Get three symbols in a row, column or diagonal to win.
